# Halloween AI — Official Website

A responsive public-facing website for Halloween AI, including the homepage, Privacy Policy and Terms & Conditions.

## Pages
- `index.html` — product introduction, feature overview, product approach, FAQ and support contact
- `privacy-policy.html` — information handling, on-device processing, optional integrations, permissions, retention and privacy requests
- `terms.html` — eligibility, acceptable use, AI output, user content, third-party services and general terms

## Assets
- `assets/style.css` — responsive visual system shared by all pages
- `assets/site.js` — accessible mobile navigation and automatic footer year
- `assets/app-icon.png` — app identity and favicon

## Deploy with GitHub Pages
1. Create a repository named `halloween-ai-official-website` (or use your preferred repository name).
2. Upload the contents of this folder to the repository root, not the enclosing folder itself.
3. Confirm `index.html`, `privacy-policy.html`, `terms.html` and `assets/` are at the root level.
4. Open **Settings → Pages** in GitHub.
5. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for the deployment and test the published site on desktop and mobile.
